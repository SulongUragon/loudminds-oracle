1. https://twelvedata.com/register          ← API key (free)
2. https://github.com/new                    ← repo creation

## After deploy — your URLs
- Backend health:   https://oracle-api.YOUR_DOMAIN/api/health
- Backend alerts:   https://oracle-api.YOUR_DOMAIN/api/alerts
- Frontend app:     https://oracle.YOUR_DOMAIN
- WebSocket:        wss://oracle-api.YOUR_DOMAIN/ws

## Where to manage things
- Backend env vars / logs:  Railway dashboard → your service
- Frontend deploys:         Cloudflare → Workers & Pages → loudminds-oracle
- DNS records:              Cloudflare → your domain → DNS
- API key usage:            https://twelvedata.com/account/usage
